# Aabhaas – AI Hybrid Landslide Prediction

## 📌 Overview

**Aabhaas** is an AI-based hybrid landslide prediction system designed to analyze environmental and geographical factors to identify areas that may be vulnerable to landslides.

The project combines machine learning techniques with environmental data to support early prediction and visualization of potential landslide-prone regions.

## 🚀 Features

* AI/ML-based landslide prediction
* Environmental data analysis
* Geospatial data processing
* Interactive visualization
* Risk-area identification
* Web-based interface
* Data-driven prediction and analysis

## 🛠️ Technologies Used

* Python
* Machine Learning
* NumPy
* Pandas
* Xarray
* Streamlit
* Plotly
* FastAPI
* Uvicorn
* GRIB / ecCodes

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/bhanusharanyadav/Aabhaas.git
cd Aabhaas
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

If the application uses Streamlit:

```bash
streamlit run app.py
```

If it uses FastAPI:

```bash
uvicorn main:app --reload
```
